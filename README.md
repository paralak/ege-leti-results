# ЕГЭ ЛЭТИ — проверка результатов

Локальная программа для проверки ответов на варианты ЕГЭ по информатике. Проект запускается в оболочке [phpDesktop Chrome](https://github.com/cztomczak/phpdesktop).

## Установка

1. Скачайте и распакуйте phpDesktop Chrome для Windows.
2. Скопируйте `settings.json` и папку `www` из этого репозитория в каталог phpDesktop с заменой файлов.
3. Запустите `phpdesktop-chrome.exe`.

## Использование

Загрузите в программу два XML-файла:

- `tasks_with_answers.xml` из конструктора вариантов;
- `answers.xml`, созданный программой тестирования.

Программа сопоставит ответы, покажет статистику и позволит скачать отчёт в формате HTML. Загруженные файлы временно сохраняются в `www/uploads` и не включаются в Git.
